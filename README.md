# Circuitnest (sai-circuitnest-tech)

Diamond storefront — Futuristic — HUD lines, neon accents on deep navy.

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build

## Features

- Style-map unique homepage (hud-hero)
- Niche film hero + soft CSS motion
- Catalog, deep PDP, offers, reviews, AI assistant
- Cart → checkout → success (demo payments)
- Special experience at `/special`

Demo only — no real payments.
